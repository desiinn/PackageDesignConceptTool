# Food Package Design Concept Sheet Tool

食品パッケージデザインのコンセプト構築および、クライアントとデザイナー間の視覚的コミュニケーションを円滑にするためのWebベースのヒアリング・思考整理ツールです。
7つのステップに沿って入力・選択を進めることで、脳内にある抽象的なイメージを論理的かつ視覚的に体系化した「コンセプトシート」を生成できます。

🔗 **ツールURL:** [https://desiinn.github.io/PackageDesignConceptTool/](https://desiinn.github.io/PackageDesignConceptTool/)

## 📌 開発の背景と目的

食品のパッケージデザイン開発において、クライアント（事業者）の抱くイメージと、デザイナーが捉えるビジュアル表現の間にミスマッチが生じることが少なくありません。
本ツールは、デザインの発注・企画段階において、商品の基本情報、ターゲット層、売り場、トーン＆マナー（キーワードとAI生成画像）をステップバイステップで整理。双方の「想い」と「形」のズレをなくし、デザインプロジェクトの起点を支える対話の道具として開発されました。

## ✨ 主な機能

- **7ステップの直感的な要素入力**: 商品情報からターゲット、売り場、イメージキーワードまでを段階的に整理。
- **キーワード連動型の参考イメージ選択**: 選択したキーワードに応じて、関連するパッケージ参考画像を最大10枚まで選択可能。
- **コンセプトシートの生成と出力**: 入力内容を1枚にまとめたシートを別ウィンドウで生成。「印刷 / PDF保存」機能により、打ち合わせ資料として即座に出力可能。
- **データマネジメント機能（ローカル保存）**: 
  - 記入途中のデータを独自のJSON設定ファイルとしてローカルに保存（エクスポート）。
  - 保存したJSONファイルを読み込むことで、過去の編集状態を完全に復元・再編集可能（インポート）。
- **サンプルデータ入力機能**: 操作感を試せるよう、コーヒーの商品データをワンクリックで自動入力する機能を搭載。

## 🛠️ 技術スタック / 仕様

外部サーバーやデータベースを使用せず、ブラウザ側のみで処理が完結する軽量な静的Webアプリケーション（HTML/CSS/JavaScript）として構築されています。

- **フロントエンド**: HTML5 / CSS3 / JavaScript (Vanilla JS)
- **アイコンフォント**: Font Awesome 6.4.0 (CDN)
- **公開・ホスティング**: GitHub Pages
- **開発プロセス**: AI支援開発（AI-Assisted Development）

### 💡 画像表示の仕組み（ロジック）
`script.js` 内に定義された画像データベース（ファイル名にタグが含まれる形式）を基に、選択されたキーワードと部分一致（OR条件）する画像を抽出します。さらに、**選択されたキーワードとのマッチ数が多い画像が上位に表示されるよう、降順で自動ソート**するアルゴリズムを実装しています。

## 🚀 使い方

1. **基本情報の入力**: 商品名、カテゴリー、内容量、必須表示事項・デザイン制約を入力します。
2. **属性・売り場の選択**: 想定するメインのターゲット（1つ選択）と、製品が並ぶ売り場（複数選択可）を選びます。
3. **キーワードと画像の選択**: イメージに近いキーワードを選択すると連動して画像が表示されるので、最大10枚までイメージに合うものを選択します。
4. **シートの生成・保存**: 「コンセプトシートを生成」からPDF保存や印刷を行います。作業を中断・保存したい場合は、フッターの「記入したデータを保存」からJSONファイルをダウンロードしてください。
